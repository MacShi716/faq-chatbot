## 1. 싱쯔쥔 — FAQ 30건 작성

**목표**: `data/faq.csv` 에 실제 답변이 들어간 항목 30개.

**우선순위**: 학사(휴학·복학·수강신청·졸업학점·성적) → 생활(기숙사·식당·교통·사무실 위치) → 장학.

**작성 순서** (한 항목당 10분):

1. 학교 홈페이지 / 학과 공지 / 학사규정에서 **실제 내용**을 확인한다.
2. `docs/데이터수집_양식.csv` 를 열어 한 줄을 복사한다.
3. 채운다:
   - `id` : `F14` 부터 이어서 (F01~F13 은 이미 있음)
   - `question_ko` : 실제로 들은 질문 + 다른 표현을 `|` 로 3개 이상
   - `question_zh` : 중국어 표현 1~2개
   - `answer` : 확인한 내용. 3문장 이내. **추측 금지**
   - `answer_zh` : 위 답변을 중국어로
   - `source` : `학과 공지 2026-12호`, `학사규정 제15조` 처럼 원문 표시
   - `checked_at` : 실제로 확인한 날짜 `2026-10-25`
   - `category` : 학사 / 장학 / 생활
   - `tags` : 명사 5개 이상, 한국어·중국어 섞어서. `어디`, `언제`, `怎么办` 같은 범용어 금지
4. `data/faq.csv` 맨 아래에 붙여넣는다.

**좋은 예 / 나쁜 예**

```
나쁨: answer = 휴학은 학과 사무실에 문의하세요.            ← 정보가 없음
좋음: answer = 휴학 신청은 3월 2일~13일, 9월 1일~11일입니다.
              신청서는 학과 사무실(제1공학관 302호)에 제출합니다.
      source = 학과 공지 2026-12호 / checked_at = 2026-10-25
```

**확인 못 한 항목**은 `[작성 필요]` 로 두고 **커밋하지 않는다.**

**끝나면**:
```
python validate_data.py
```
ERROR 0 이면 통과. WARN 은 남아 있어도 된다.

## 2. 잔쯔졔 + 스친하오 — 블라인드 평가 문항 50개

**목표**: `data/eval.csv` 를 **새로** 작성. 한국어 25 + 중국어 25.

**중요 규칙** — 이걸 어기면 측정이 무의미해진다:

- `data/faq.csv` 의 `tags` 컬럼을 **보지 않는다**
- `question_ko` / `question_zh` 를 **그대로 베끼지 않는다** (표현을 바꿔 쓴다)
- 실제로 물어볼 법한 말투로 쓴다 (친구에게 묻듯이)

**형식** (`data/eval.csv`):

```
qid,lang,question,expected_id
K01,ko,쉬는 학기 어떻게 신청해,K02
Z01,zh,怎么申请休学,K02
```

`expected_id` 는 그 질문에 맞는 FAQ 의 id. 맞는 항목이 없으면 그 문항은 빼고 다른 걸 쓴다.

**끝나면**:
```
python evaluate.py --method difflib
```
숫자가 나오면 스친하오에게 공유.
