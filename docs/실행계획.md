# 실행계획 (2026.10.23 ~ 2026.12.15)

> 기준 문서: 캡스톤디자인 과제계획서 §3(수행방법)·§4(일정), 산학협력프로젝트 계획서.
> 계획서의 15주 간트는 9월 시작 기준이다. 실제 착수일(10/23)에 맞춰 **남은 8주**로 다시 압축한 것이 이 문서다.

## 0. 현재 위치

| 항목 | 계획서상 | 실제 |
|---|---|---|
| 간트 주차 | 8주차(정확도 평가 단계) | **1주차(환경 착수)** |
| 코드 | 1단계 규칙 기반 완성 | 검색·평가 파이프라인 가동 |

→ 계획 대비 **약 6~7주 지연**. 만회 전략은 "데이터 수집과 개발을 병렬로 돌리고, 2단계(LLM)는 선택 기능으로 뒤로 미룬다"이다.
2단계를 못 해도 1단계 완성만으로 계획서상 성과물 요건(정확도 70%·비교 보고서)은 충족된다.
