## 알려진 문제

1. 한국어 질문이 엉뚱한 FAQ 로 붙는 사례가 있다.
   예: `수강신청 날짜 알려주세요` → F02(복학) 0.50, F04(수강신청) 0.50 동점.
   → 10/23 동점 처리 규칙(태그 → 질문 길이 → id)으로 정렬은 결정적이 됐지만,
     태그 보정에 의존하는 구조는 그대로다. 오답 상위 20건 원인 분류가 남았다.
2. 키워드 태그 보정은 **오탐 위험**이 있다. 태그가 질문에 들어 있으면 무조건 0.7 점을 주므로
   `成绩不好会退学吗` 처럼 다른 의도의 질문도 F05 로 붙는다. 태그를 흔한 단어로 늘리면 악화된다.
   실측 오답: K12 `성적 장학금 기준` → F05·F06 0.700 동점 후 F05(오답) 선택.
3. 모든 `answer` 가 `[작성 필요]` 상태 — 발표 전 반드시 실제 확인 내용으로 교체.
4. `answer_zh` 컬럼과 폴백 표시는 구현됨. 다만 13행 모두 `[작성 필요]` 라
   현재 中文 화면은 `[작성 필요] 请确认…` 중국어 초안 + 주황 '미확인' 배지로 나온다(`answer_zh` 가 완전히 비면 한국어 원문 폴백). → 실제 번역 확인이 남은 일.
5. 발표자료에 쓰인 화면 캡처가 **12건 시절 캡처**를 포함한다(한국어 화면은 채팅 영역만 잘라 사용).
   13건 기준으로 다시 캡처하면 더 정확하다.
6. (해결됨) 검색 방식·화면 언어를 바꿔도 이전 답변의 출처 줄이 유지된다
   (history 에 FAQ·점수를 저장하고 현재 언어로 다시 그림).
