## 알려진 문제

1. 한국어 질문이 엉뚱한 FAQ 로 붙는 사례가 있다.
   예: `수강신청 날짜 알려주세요` → F02(복학) 0.50, F04(수강신청) 0.50 동점.
   → 동점 처리 규칙(카테고리/질문 길이/키워드 가중) 필요.
2. 짧은 중국어 질문이 임계값에 걸린다. 예: `宿舍费用多少` → 0.33 으로 미응답.
   → `question_zh` 표현을 1개에서 3개로 확대.
3. 모든 `answer` 가 `[작성 필요]` 상태 — 발표 전 반드시 실제 확인 내용으로 교체.
4. 화면 언어를 中文 으로 바꿔도 **답변 본문은 한국어**로 나온다(FAQ 에 한국어 답변만 있음).
   → `faq.csv` 에 `answer_zh` 컬럼을 추가할지 2주차에 결정 필요.
